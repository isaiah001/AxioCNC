# Appearance Settings

**Settings → Appearance** controls theme, custom themes, and accent color.

## Theme mode

**Theme mode** — Light, **Dark**, or **System**.

- **Light** — Light background.
- **Dark** — Dark background.
- **System** — Follow the OS light/dark setting.

## Custom theme

**Custom theme** — Use a user- or community-created theme.

- **Default theme** — Use the built-in theme (no custom theme).
- **Installed themes** — List of themes in your themes folder. Pick one to apply.
- **Upload** — Install a theme from a JSON file.
- **Refresh** — Reload the list (e.g. after dropping a theme file into the themes folder).
- **Delete** — Remove an installed custom theme.

When a custom theme is active, **Accent color** is ignored.

## Accent color

**Accent color** — Primary color for buttons and highlights. Only applies when **no** custom theme is selected.

Options: **Orange** (default), **Blue**, **Green**, **Purple**, **Red**, **Zinc**.
