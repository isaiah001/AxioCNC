# Advanced Settings

**Settings → Advanced** exposes options for debugging and development. Most users don’t need these.

:::note
These options are not typically needed for normal use. Use them only if you’re debugging or working on AxioCNC itself.
:::

## Show advanced settings

**Show advanced settings** — When **off**, the **Advanced** section is hidden from the sidebar. Turn it **on** to see and use the options below.

## Debug mode

**Debug mode** — When **on**, enables extra debug logging and development-oriented behavior. Use only when troubleshooting or developing. Turn **off** for everyday use.
