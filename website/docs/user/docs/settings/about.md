# About

**Settings → About** shows version information, update preferences, usage data, and links.

## Version information

- **Current version** — Installed AxioCNC version.
- **Available version** — Latest release (when **Notify me of updates** is on and the app can check). Shown as “Update available” when newer.

## Notify me of updates

**Notify me of updates** — When **on**, AxioCNC checks for new versions (e.g. on startup). You’ll see a notification when an update is available. When **off**, no update check is performed.

## Anonymous usage data

**Anonymous usage data** — When **on**, AxioCNC sends anonymous usage statistics to help improve the software. No personal data or G-code is sent. The project uses [Aptabase](https://aptabase.com), a privacy-focused analytics service. You can turn this **off** at any time.

## Links

- **Show Setup Tutorial** — Reopens the first-use setup walkthrough.
- **GitHub Repository** — Source code, issues, and contributions.
- **Documentation** — Guides and reference (this docs site).
- **Support the Project** — GitHub Sponsors link.

AxioCNC is open source. License details are linked from the About section (e.g. MIT).
