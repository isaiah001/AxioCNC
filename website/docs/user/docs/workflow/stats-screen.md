# Stats Screen

The **Stats** screen shows job history, run statistics, and tool usage. Use it to review past jobs and see how much you’ve run.

## What you’ll do

- View a list of past jobs
- See aggregate statistics (total jobs, runtime, etc.)
- Inspect tool usage across jobs
- Open job details when available

## When to use it

Use Stats after jobs to confirm they ran, check duration, or look up prior runs. Helpful for maintenance (e.g. tool life) and general record‑keeping.

## Main elements

| Element | Purpose |
|--------|---------|
| **Job history** | Table of completed (and sometimes aborted) jobs |
| **Statistics** | Totals such as job count, total runtime |
| **Tool usage** | Per‑tool usage across jobs |
| **Job details** | Click a job (when supported) for more info |

## What you’ll see

- **Job list** — Date, file name, duration, result (e.g. completed, stopped). Sort or filter depending on the UI.
- **Stats** — e.g. total number of jobs, total cutting time.
- **Tools** — Which tools were used and how often (or how long), when tracked.
